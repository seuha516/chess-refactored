# 체스 규칙: 기준과 검증

## 기준 문서

1. **FIDE Laws of Chess** — 2023년 1월 1일 시행판(2026년 9월 확인 시점의 현행판).
   <https://handbook.fide.com/chapter/e012023>
   기물의 이동(제1–3조: 폰, 앙파상, 승진, 캐슬링, 체크, 합법 수)은 이 규정을 따릅니다.
2. **FIDE Online Chess Regulations**, Part I 기본 규칙. <https://handbook.fide.com/chapter/OnlineChessRegulations>
   온라인 대국에서는 Laws 제4·5조를 이 규정의 제3·5조가 대체합니다(제1.3조). 게임 종료 판정은 이 규정을 따릅니다.

외부 라이브러리(chess.js)는 교차 검증용 오라클로만 사용하며, 정답의 기준으로 삼지 않습니다.

오프라인 규정(Laws 9.2·9.3)은 3회 반복과 50수를 *청구*해야 하는 무승부로 정하지만, 온라인 규정은 자동 무승부로
정합니다. 원본도 자동으로 처리했으므로 동작 의도는 유지하되, 판정 방법을 규정에 맞게 고쳤습니다.
자동 판정이 먼저 적용되므로 5회 반복·75수(Laws 9.6)는 별도로 다룰 필요가 없습니다.

### 국면 동일성 (Laws 9.2.3)

"같은 플레이어가 둘 차례이고, 같은 종류·색의 기물이 같은 칸에 있으며, 양쪽의 가능한 수가 모두 같을 때"
같은 국면입니다. 구현(`repetitionKey`)은 기물 배치, 둘 차례, **영구적인** 캐슬링 권리, 그리고 **실제로 가능한**
앙파상 칸을 비교합니다. 일시적으로 캐슬링할 수 없는 상태(사이에 기물, 공격받는 칸)는 권리를 바꾸지 않으므로
포함하지 않습니다.

### 메이트 가능 여부 (시간 초과, 기물 부족)

"어떤 합법 수순으로도 체크메이트할 수 없는가"를 기물 구성으로 판단합니다(`canCheckmate`).

- 킹만 남음 → 불가
- 킹 + 나이트 1개 → 상대에게 폰·나이트·비숍·룩이 있을 때만 가능(상대 기물이 자기 킹을 막아 주는 수순)
- 킹 + 한 색 칸의 비숍들 → 상대에게 폰·나이트 또는 다른 색 칸의 비숍이 있을 때만 가능
- 그 밖(폰·룩·퀸, 서로 다른 색 칸의 비숍, 나이트 2개, 나이트+비숍 등) → 가능

양쪽 모두 불가하면 그 자체로 무승부 국면(5.2.2)입니다.

`test/legacy/rules.test.js`, 원본 제거와 함께 삭제). 수정된 동작은 `test/chess`에서 `legacy:`로 시작하는

## 검증 방법

- **조항별 단위 테스트** (`test/chess/rules.test.ts`, `san.test.ts`): 위 표의 각 규칙과 경계 상황.
- **Perft** (`test/chess/perft.test.ts`): 정해진 깊이까지의 합법 수 트리 노드 수를 Chess Programming Wiki의
  표준 6개 국면 값과 비교합니다(<https://www.chessprogramming.org/Perft_Results>). 이 값은 규칙만으로 결정되므로
  캐슬링·앙파상·승진·핀 처리의 오류를 매우 민감하게 잡아냅니다. 약 50만 노드, 모두 일치.
- **차분 테스트** (`test/chess/differential.test.ts`): 시드 고정 무작위 대국을 chess.js와 동시에 진행하며 매 수마다
  합법 수 집합, 모든 합법 수의 SAN, 국면(FEN), 체크, 종료 판정을 비교합니다. 기본은 빠른 표본이고,
  `DIFFERENTIAL_GAMES=25`로 175판·29,109국면(체크메이트 11, 스테일메이트 5, 기물 부족 94, 3회 반복 1)을
  검사했을 때 불일치가 없었습니다.

## 알려진 한계

- **기물 구성 외의 이유로 막힌 국면**(예: 폰이 서로 막혀 어느 쪽도 뚫을 수 없는 경우)은 무승부 국면으로 자동
  판정하지 않습니다. 이런 국면은 일반적으로 판정이 어렵고, 결국 50수·반복 규칙이나 합의로 끝납니다.
- `canCheckmate`는 기물 구성에 따른 판정입니다. 예를 들어 "킹+나이트 대 킹+퀸"은 메이트 불가로 판정합니다.
  lichess의 [`InsufficientMatingMaterial`](https://github.com/lichess-org/scalachess/blob/master/core/src/main/scala/InsufficientMatingMaterial.scala)과
  같은 기준임을 확인했지만, 모든 배치를 탐색해 증명한 결과는 아닙니다.
- 시간 제도는 원본의 "한 수당 3분"을 유지했습니다. 누적 시계(예: 5분 + 증초)는 도입하지 않았습니다.
